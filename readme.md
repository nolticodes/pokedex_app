# Pokedex App

A browser-based Pokédex application built with vanilla JavaScript using data from the PokéAPI.

The application allows users to browse Pokémon, search for specific Pokémon, and view detailed information including types, stats, and images.

---

## Features

- Dynamic Pokémon rendering
- Live search functionality
- Pokémon detail overlay
- API-based data fetching
- Responsive card layout
- Loading animations
- Type-based styling
- "Load More" functionality
- Smooth user interactions

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- REST API
- PokéAPI

---

## Functionality

The application fetches Pokémon data directly from the PokéAPI and displays interactive Pokémon cards.

### Included Features

- Browse Pokémon list
- Search Pokémon by name
- Open Pokémon detail view
- Display Pokémon types
- Load additional Pokémon dynamically
- Responsive design for different screen sizes

---
